Principles
02Design principles

Four rules.
The rest follows.

01

Editorial restraint

Newspaper page, not dashboard. Hairline rules separate ideas. Whitespace does the heavy lifting. Decoration is suspect.

Not Glossy. Gradients. Glow.
02

Evidence over decoration

Numbers earn their size. Quotes get their own slide. Process gets a diagram, not an icon. If it isn't load-bearing, it isn't on the page.

Not Stock photos. Generic illustrations.
03

One accent. Used like punctuation.

Ink, white, four greys, and one Primary purple. The accent shows up at brand moments — symbol, eyebrow numerals, live dots — never as a background wash or text fill.

Not Brand-color washes. Tint accents. Purple text blocks.
04

Grid-anchored

Every element sits on a column. Headers and footers carry the same weight on every slide. Consistency is the personality.

Not Centered free-floats. Composition gymnastics.

Logo & wordmark
03Logo & wordmark

A symbol in primary,
locked to a wordmark in ink.

Symbol
Primary lockup DASH
Sub-brand lockup DASHLogistic
Reverse on Ink DASHLogistic

Construction

Symbol — a stylized D in Primary (#5E2AAC). Wordmark — Plus Jakarta Sans, weight 800, tracking -0.025em, in Ink.

Lockup

Symbol sits left of the wordmark at 0.92× cap-height. Gap between them = 0.32em. Symbol always in Primary; wordmark always in Ink (or White on inverse).

Sub-brand

Sub-brand follows DASH separated by a 1px rule. Sub-brand at 0.32em of the wordmark, weight 600, tracked 0.18em, all caps, in Neutral.

Clear space

Half the cap-height of D on every side. The slide header reserves 16px below; never less.

Minimum size

Header form: symbol 10px, wordmark 10px/800. Below that, the symbol stands alone. Below 16px, drop the sub-brand.

Don't

Don't recolor the symbol (always Primary or White-on-Ink). Don't outline. Don't separate symbol from wordmark in the same composition.

Contrast
Ink on white = 14.4 : 1 (AAA). Primary on white = 8.6 : 1 (AAA). Neutral on white = 6.7 : 1 (AA). Never set Neutral on Tint.

Typography
05Typography

One sans for everything.
One mono for evidence.

.huge / 800 Aa
.large / 700 Cross-dock, end to end.
.medium / 600 Eight scan events. One audit trail.
.lede / 400 Items in the same zone usually move together. Bags carry color, batches carry route.
.body / 400 Scan, sort, batch, deliver.
.label / 600 caps Section heading
.mono / code ScanEvent: facility_inbound
Families

Display & text — Plus Jakarta Sans

Code & evidence — JetBrains Mono

Fallback — -apple-system, BlinkMacSystemFont, system-ui, sans-serif

Weight ladder
Aa Aa Aa Aa Aa Aa Aa

Display headlines lean on 200 & 800. Body sits at 400. Labels and labels-as-buttons at 600 / 700.

Letter-spacing rule

Tighter as text gets larger. Display: -0.045em. Lede: -0.005em. Labels (uppercase): +0.18 to 0.22em. Mono: 0.

Numerals

Always tabular. font-variant-numeric: tabular-nums on stats, page numbers, dates, IDs.

OpenType features

Body inherits font-feature-settings: "ss01", "cv11", "cv02" for the working forms.

One face. Seven weights. Tabular numerals. 06 / 12

Grid & layout
06Grid & layout

Header, body, footer.
Always in that order.

Header · 10px caps
Content · centered, max-width 64ch
Footer · 10px caps
16:9 · 100vw × 100vh Safe area · clamp(24,3.5vh,44) × clamp(40,7vw,96)
Canvas
width: 100vw; height: 100vh;

Each slide fills the viewport. Scroll-snap forces one slide per page.

Safe area
padding: clamp(24px, 3.5vh, 44px) clamp(40px, 7vw, 96px);

Vertical and horizontal padding scales with viewport, then clamps. Never edit raw pixel values.

Three zones
display: flex; flex-direction: column;

Header (auto) · Content (flex 1, justify-content center) · Footer (auto). Hairline rules above and below at 10% black.

Common grids
grid-template-columns: repeat(2, 1fr); /* facts */ repeat(3, 1fr); /* concepts */ repeat(8, 1fr); /* flow */

Use 2-col for comparisons, 3-col for triads, 8-col only for the end-to-end flow.

Stroke
Always 1. Always currentColor. Never filled (except a small white inset for relief).
Frame
Always inside a 44×44 1px square. Icon centered. Never breathes outside the frame.
Sizing
Glyph occupies ~24px of the 44px frame. Stroke does not scale with display size.
Use sparingly

Voice & copy
09Voice & copy

Plain verbs. Short sentences.
Numbers when you have them.

Sentence-level rules

case Sentence case for everything except labels and the wordmark. Headlines do not capitalize every word.
length Two sentences max in headlines. Cap lines at 24 to 28ch on display copy.
verbs Use working verbs: scan, sort, batch, reconcile. Not "perform reconciliation activities."
numbers Numbers earn their size. 50–500 uses an en-dash. 1st-mile uses a hyphen.
acronyms Always all-caps: POD, SLA, ETA, B2B, 4W, 2W. No periods.
jargon Use the operator's word, not the engineer's: "bag" not "container." "hub" not "facility node."

Document-level rules

eyebrow Every section opens with a numbered tag: 01 · The problem. Tracking 0.22em, weight 600.
labels All UI labels in UPPERCASE with tracking 0.18–0.22em. Reads as a system, not a sentence.
footers Footer takes a single useful sentence (source, principle, one-liner) plus the page count. Never empty.
quotes Use typographic curls (\201C \201D), never straight quotes. Single quotes inside doubles.
em-dash No spaces around an em-dash in headlines — like this. Spaces around it in body copy — like this.
code voice Inline code is always literal: items.create, Job.destination_type. No paraphrasing inside the box.

Do / Don't
10Do / Don't

The fastest way to stay on-brand.
Read both columns, then ship.

Do

Keep Primary as an accent.

Logo, eyebrow numerals, live dot, do-marker, selection. Ink, white, four greys carry the rest.

Don't

Wash surfaces in Primary.

No purple page backgrounds, no purple body text, no purple buttons. The accent loses its job the moment it spreads.

Do

Align everything to the rule.

Every block sits on a 1px hairline at 10% black. Rows, cards, columns. The grid does the talking.

Don't

Float content centered in space.

No orphan paragraphs in the middle of a slide. If it isn't on the grid, it isn't on the slide.

Do

Use tabular numerals on every figure.

Stats, dates, page counts, IDs. font-variant-numeric: tabular-nums.

Don't

Mix proportional and tabular figures.

Numerals jiggle when set proportional in a column. They must align vertically on every row.

Do

Invert backgrounds for terminal states.

Black surface = the end of a flow. Used for the final step in the 8-step lifecycle. One per slide, max.

Don't

Use black surfaces as a styling flourish.

If everything is "premium," nothing is. Inversion has a job — keep it loud by keeping it rare.
