00Walkthrough · for SwipeRX

When a recipient won't accept, both sides see it within seconds.

A return today means a phone call, a photo on WhatsApp, and a ticket to reconcile. With this flow the rider files the return at the counter — reason, photo, signature — and it surfaces on Dash Link instantly, with the waybill and the photo proof on the same screen. No follow-up email, no PDF, no missing context.

01 · The rider's side 02 · The handoff 03 · The client's side
01The rider's side

Three taps at the counter — reason, photo, signature.

The "Report return" CTA sits next to "Complete delivery" on every active stop. It opens a four-screen flow that works offline; the photo and signature upload when the radio comes back. Item-level granularity is out of scope — the return is recorded against the waybill, not against each SKU.

02The handoff

The exact record that moves from the field to Dash Link.

Nothing else is captured. Five fields per return, plus the rider's optional note. The client portal renders this record directly — no transformation, no manual reconciliation.

03The client's side · Dash Link

A returned delivery shows up three places at once.

A counter at the top of the dashboard, a status pill in the row, and a focused drawer that puts the waybill, the delivery ID, and the photo proof on the same screen. The client never has to ask for context.

04What this changes for SwipeRX

One source of truth for returns.

Every refused batch shows up on Dash Link the moment the rider logs it — with the waybill, the delivery ID, the reason, and three photos. No more WhatsApp screenshots, no manual ticket reconciliation, no follow-up email to identify which order the return belongs to.

05Out of scope · v1

What we're not doing yet.

  • Item-level returns (per-SKU quantity). The return is recorded against the waybill.
  • In-portal dispute submission. The button is stubbed; flow lands in the next iteration.
  • Photo lightbox / EXIF inspector. Click-to-enlarge ships with v1.1.
  • CSV / API export of returns. Available once the data model stabilizes.
